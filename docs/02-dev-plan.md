## 2. 연속적인 문제음 처리

격자(12음 × 7옥타브 × 12토닉)를 외우지 못하게, **토닉 주파수 자체를 연속값으로** 뽑는다.

- 매 문제(또는 매 라운드) 토닉 = 12개 음 중 무작위 + **±50센트 실수 디튠** → 결과적으로 토닉 주파수가 로그 스케일에서 연속 균등분포. 디그리 간 관계는 12평균율로 정확히 유지.
- 함께 무작위화: **음역**(문제음 옥타브, 토닉 위/아래 무관), **음색**, 세기, 길이, **맥락 종류**(아래).
- 모든 음은 `freq = tonicHz × 2^(semitones/12)`로 직접 합성하므로 어떤 실수 주파수도 문제 없음.
- 기록에 토닉 Hz, 디튠 센트, 음역, 음색, 맥락을 전부 남겨서 나중에 **"같은 디그리 정확도가 토닉 높이/음역/음색에 따라 달라지는가"**를 볼 수 있게 함 (달라지면 관계가 아니라 표면 단서를 쓰는 신호).

### 맥락 풀 (문제 전 조성 확립)
매번 무작위로 하나: 장조 카덴스(I–IV–V–I, I–ii–V–I, I–vi–IV–V–I, I–IV–I), 단조 카덴스(i–iv–V–i, i–VI–iv–V–i), 토닉 드론, 스케일 상/하행, 아르페지오. 보이싱·자리바꿈·음역·**마지막 화음의 최상단 음**을 무작위화. v1은 장조 + 단조(자연/화성), 선법은 다음 버전.

## 3. 음색 (피아노 아님, 하지만 피아노에서 나와도 어색하지 않은 맑은 소리)

샘플 없이 합성 (모든 주파수에서 품질 동일):
1. **Glass Bell / 셀레스타풍** — FM 합성, 맑고 짧은 감쇠
2. **Soft E-Piano (로즈풍)** — FM, 피아노와 가장 가까운 따뜻한 타건음
3. **Music Box / 글로켄** — 높은 배음, 반짝이는 소리 (별 테마와 어울림)
4. **Plucked String** — Karplus-Strong 하프/기타풍
5. **Warm Pad / 오르간** — 감쇠 없는 지속음, **드론 전용 기본값**
6. **Soft Flute** — 사인 + 약간의 숨소리

문제마다 활성화된 음색 중 무작위 (설정에서 켜고 끄기).

## 4. 훈련 v1

### 4.1 개별 음 맞추기 (B1)
맥락 → 문제음 1개 → 디그리 버튼(객관식). 오답이든 정답이든 **해결 선율**(예: 6→7→1)을 들려줌. 다시 듣기 / 맥락 다시 듣기 버튼. 옵션: 드론 위에서 듣기.
- 디그리 세트 프리셋: `1·3·5` → `다이아토닉 7개` → `크로매틱 12개`, 또는 직접 선택.

### 4.2 멜로딕 딕테이션 (C1)
맥락 → 2~8음 멜로디 → 순서대로 디그리 입력 → 음마다 채점.
- **의도치 않은 전조 방지**: 토닉 화음음에서 시작·끝 / 크로매틱 음은 바로 순차 해결 / ♯4→5 같은 토니시제이션 패턴 제한 / 길면 1도 재등장 강제.
- 생성 후 **Krumhansl–Schmuckler 키 판정**을 (맥락+멜로디)에 적용해, 의도한 키가 1위가 아니거나 2위와 차이가 작으면 다시 생성.
- 첫 음 힌트 옵션(C2).

## 5. 기록 (지우지 않고 계속 쌓기)

**추가만 하는(append-only) 이벤트 로그**. 수정·삭제 없음.

- **세션**: 시작/종료 시각, 훈련 종류, 설정 전체 스냅샷, 기기/앱 버전.
- **문제(trial)마다**:
  - 문제 설정: 훈련 종류, **보기 세트(가능한 답 목록과 개수)**, 디그리 풀, 조성/선법, 맥락 종류, 토닉 Hz, 디튠 센트, 음역, 음색, 템포, 멜로디 길이
  - 출제 방식: **random / biased**, biased면 어떤 약점 패턴을 노렸는지, 4문제 블록 안 위치
  - 정답과 사용자 답 (딕테이션은 음별)
  - 시각: 문제 제시, 소리 재생 끝, **각 입력 시각**(딕테이션 음별 입력 간격 포함), 제출. 이전 응답과의 간격.
  - 다시 듣기 / 맥락 다시 듣기 횟수
- **찍기 보정**: 보기 개수를 기록하므로 우연 정답률(1/보기 수)을 뺀 점수, 그리고 디그리별 **"그 답을 얼마나 자주 눌렀나"(오경보율)**를 같이 계산. "긴가민가하면 파" 하는 사용자는 파의 정답률은 높지만 오경보율도 높게 나와서 구분됨 (신호탐지 d′ 방식).
- **반응 시간**: 직관 응답(빠름)과 계산 응답(느림)을 나눠 볼 수 있게 소리 끝~응답 시간을 분포로 표시.
- **영구 보존**: `navigator.storage.persist()`로 브라우저가 지우지 못하게 요청. 오래된 세션은 gzip 압축 덩어리로 묶어 같은 DB에 보관 (원본 손실 없음). **내보내기/가져오기**(.jsonl.gz 파일)로 백업.

## 6. 적응형 출제 (핵심)

- **블록 구성**: 4문제 = **랜덤 2개 연속 + 편향 2개 연속**, 블록마다 RR-BB / BB-RR 순서 무작위. 사용자에게는 표시 안 함.
- **가정: 사용자는 바로 이전 문제(와 세션)에만 영향받음.** 그래서 각 쌍의 **두 번째 문제는 같은 모드의 문제 뒤에 오므로 "깨끗한" 측정**이 됨. 비교 통계는 두 번째 문제 위주로 계산하고, 첫 번째는 전환 효과 분석용으로 따로 봄.
- **약점 패턴**: 개별 음은 (디그리), (이전 디그리→현재 디그리), (디그리×음역), (디그리×음색). 딕테이션은 (음정 전이 2음 묶음), (위치별 디그리). 패턴마다 오답률을 베타 분포로 추정하고 최근 기록에 가중치(지수 감쇠), 반응이 느린 정답도 반쯤 약점으로 침.
- **편향 문제**: 약점 패턴을 톰슨 샘플링으로 뽑아 그 패턴이 들어가는 문제 생성 (한 패턴만 계속 나오지 않게 다양성 유지).
- **비교 화면** (한눈에):
  1. 랜덤 문제 정확도 추이 (전체 실력의 편향 없는 추정)
  2. 최근 약점 패턴의 정확도 추이: **랜덤 문제에서 우연히 나왔을 때** vs **편향 문제에서**
  3. 디그리별 혼동 행렬, 찍기 보정 점수, 반응 시간 분포
  4. 토닉 높이·음역·음색별 정확도 편차 (관계 학습 여부)
